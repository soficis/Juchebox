# Sideloading

This project distributes source first. iOS installation requires signing.

## Xcode

1. Open `Juchebox.xcodeproj`.
2. Select the `Juchebox` scheme.
3. Choose your own Apple development team.
4. Build and run on your device.

## AltStore-Style Self-Signing

Build from source you inspect yourself. Do not enter Apple ID credentials into this app or repository. Follow your signing tool's own documentation and understand its certificate refresh limits.

## Ad Hoc Beta

Ad Hoc builds are appropriate only for explicitly registered test devices. Do not advertise an IPA as universally installable on all iPhones.
